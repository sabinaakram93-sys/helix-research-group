# HELIX Research Group Website

Website for HELIX, an early-stage independent academic research network focused on human-centered AI.

The website is a self-contained static HTML page. Its logo and artwork are embedded in `index.html`, so no build step or package installation is required.

## Files

- `index.html`: the current website, including the compact introduction and connected Research Areas framework.
- `.nojekyll`: serves the static files without Jekyll processing on GitHub Pages.

Open `index.html` in a web browser to preview it locally.
